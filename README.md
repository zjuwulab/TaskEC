# TaskEC
TaskEC

This repository contains code accompanying the manuscript “Deep-learning perturbational inference of task fMRI reveals dynamic signaling reconfiguration in visual processing.”

The batch scripts implement task-fMRI time-series modeling, model comparison, and effective-connectivity analysis. A sample dataset for one HCP participant is included to illustrate the input format. Please configure the data and output paths in each script before running.

HCP data are subject to the HCP Data Use Terms: https://www.humanconnectome.org/study/hcp-young-adult/document/wu-minn-hcp-consortium-open-access-data-use-terms.
